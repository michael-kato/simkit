# Engine guide

How each simulator plugs into simkit. Everything engine-specific lives in
`src/simkit/adapters/<engine>.py`; nothing outside that file should change
when switching engines.

## Conventions at a glance

| Engine | Handedness | Up | Forward | Units | Camera looks down | Robot import |
|---|---|---|---|---|---|---|
| **canonical (ROS)** | right | +Z | +X | m | +Z (optical frame) | URDF |
| Gazebo Harmonic | right | +Z | +X | m | +X (sensor frame) | `gz sdf -p robot.urdf > robot.sdf` |
| Isaac Sim | right | +Z | +X | m (check `metersPerUnit`) | −Z | URDF Importer extension |
| Blender | right | +Z | — | m | −Z | URDF add-ons, or via USD |
| Unity | **left** | +Y | +Z | m | +Z | Unity URDF Importer package |
| Unreal 5 | **left** | +Z | +X | **cm** | +X | No official importer: go via USD/FBX, or rclUE tooling |

All conversions go through `simkit.frames` (`pose_to_engine`, `pose_from_engine`,
`R_BODY_OPTICAL`, `R_OPTICAL_OPENGL`). They are tested against independent
references, including the formula Unity's ROS-TCP-Connector uses.

## What each engine is good for

| | Closed-loop robot sim | ROS 2 | Photorealism | Labels out of the box | GPU |
|---|---|---|---|---|---|
| Gazebo | ✅ | native (`ros_gz`) | low | segmentation + bbox sensors | any |
| Isaac Sim | ✅ | built-in bridge | high | Replicator annotators | NVIDIA RTX only |
| Unity | ✅ | ROS-TCP-Connector | medium | custom shaders | any |
| Unreal 5 | possible, more work | rclUE / community | high | stencil/custom passes | any |
| Blender | ❌ (images only) | ❌ | high | BlenderProc | NVIDIA, AMD (HIP), CPU |

## Adding an engine

1. Subclass `EngineAdapter`: set `name` and `convention`, implement `setup`,
   `apply`, `capture`.
2. Convert every pose *into* the engine in `apply`, and every output *back*
   in `capture` (depth in meters, instance ids = `ObjectInstance.instance_id`).
3. Never sample randomness in the adapter. Render exactly the `FrameSpec`.
4. Register it in `simkit/adapters/__init__.py`.
5. Check it against the mock: same scenario, same frame index → the same
   objects should appear in the same image regions.

## Assets

Canonical asset format is **OpenUSD** (Isaac reads it natively, and Blender
and Unreal import it). Keep engine-specific exports as siblings
(`pallet.usd`, `pallet.sdf`, `pallet.glb`) generated by a script, not by hand.
Track large binaries with Git LFS or DVC, not plain git.
